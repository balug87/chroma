# Chroma

Five daily color puzzles in one lab bench.

| Trial | What you do |
| --- | --- |
| Dial | Match a random field with three hex digits (the Guess My RGB read). |
| Pick | An RGB code is shown. Tap the chip that is that color. Five rounds, and the chips draw closer each time. |
| Pin | The RGB numbers are given. Drop a pin on a hue × lightness spectrum. |
| Odd | Find the one chip that was nudged off an otherwise even grid. |
| Gap | Put the missing stop back into a color ramp. |

Seven lives are shared across every trial. A wrong read, a wrong chip, or a spectrum pin under 80 spends one. Run out and the bench closes until the next day. Practice has its own seven, restored by New color.

Odd and Gap are extra visual trials: discrimination, and completing a gradient. Other ideas that fit the same bench — memory mix, complements, sorting a lightness ramp, naming the pigment — are noted in the footer.
